# Excel Gradebook Analysis

## Project Overview

This project is an Excel-based Gradebook Analysis and Dashboard created to organize student test scores, calculate performance statistics, identify students who may require attention, and visualize assessment results.

The workbook contains student information, scores from multiple tests, performance percentages, summary statistics, conditional formatting, and charts to make the gradebook easier to analyze and understand.

## Objectives

The main objectives of this project are:

* Organize student test results in a structured gradebook.
* Record scores for multiple assessments.
* Calculate performance percentages for each test.
* Identify students who may require additional attention.
* Analyze maximum, minimum, and average scores.
* Use conditional formatting to highlight performance.
* Create charts to compare student performance.
* Build a simple dashboard for visual analysis.
* Practice Excel formulas, formatting, and data visualization.

## Dataset

The dataset contains student records with the following assessment categories:

| Assessment              | Maximum Score |
| ----------------------- | ------------: |
| Safety Test             |            10 |
| Company Philosophy Test |            20 |
| Financial Skills Test   |           100 |
| Drug Test               |             1 |

The gradebook contains student first names, last names, individual test scores, calculated percentages, and an employee-status indicator.

### Conditional Formatting

Conditional formatting is used to make the gradebook easier to interpret.

Different formatting is applied to highlight:

* Strong performance
* Lower test scores
* Important employee-status results
* Performance variations

This allows potential problem areas to be identified quickly without manually reviewing every score.

## Dashboard

The workbook includes a visual dashboard containing charts for:

### Safety Test

A column chart compares student performance in the Safety Test.

### Financial Skills Test

A column chart compares Financial Skills Test scores across students.

### Company Philosophy Test

A column chart displays student scores for the Company Philosophy Test.

These visualizations make it easier to compare students and identify differences in performance.

## Summary Statistics

The gradebook includes summary calculations for each assessment.

| Statistic | Safety Test | Company Philosophy Test | Financial Skills Test | Drug Test |
| --------- | ----------: | ----------------------: | --------------------: | --------: |
| Maximum   |          10 |                      18 |                    99 |         1 |
| Minimum   |           6 |                       5 |                    28 |         0 |
| Average   |       8.125 |                   12.44 |                  72.2 |       0.9 |

These statistics provide a quick overview of overall student performance.

## Key Insights

The analysis provides several useful observations:

* The Safety Test has a relatively high average score compared with its maximum score.
* Financial Skills Test results show a wider variation between students.
* Company Philosophy Test results also show noticeable differences in student performance.
* The Drug Test contains binary results, where students receive either a passing or non-passing result.
* Conditional formatting helps identify students with comparatively lower scores.
* The dashboard provides a quick visual comparison of assessment performance.
